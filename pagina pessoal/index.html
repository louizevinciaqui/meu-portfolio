AUTO STOCK

Auto Stock foi desenvolvido para facilitar o gerenciamento e a organização de estoque de peças e produtos.

Sistema web de gerenciamento de estoque, desenvolvido para permitir o cadastro, consulta, edição e exclusão de produtos, além do controle de quantidade e movimentação de itens. O projeto foi desenvolvido como atividade acadêmica do curso de Análise e Desenvolvimento de Sistemas.
